# MediCheck Summary for SKKU Medical Big Data

MediCheck is a medical big data portfolio prototype designed around synthetic EHR analytics and trustworthy AI:

- cardiovascular risk prediction from structured patient features
- rule-based phenotype construction from condition tables
- data quality profiling for missingness, duplicates, code completeness, and temporal consistency
- explainable model outputs for interpretability discussions

The project is intentionally scoped as a research and education prototype, while remaining extensible toward larger EHR/CDM pipelines, multi-institutional analytics, and more advanced healthcare AI workflows.
