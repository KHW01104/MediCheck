# MediCheck Summary for Gachon DAC Lab

MediCheck is a compact healthcare AI systems project focused on practical ML engineering:

- structured EHR-style data loading and validation
- patient-level tabular modeling with baseline and boosting models
- transparent evaluation with ROC-AUC, F1, precision, recall, and confusion matrix
- explainability outputs for global and patient-level interpretation
- deployable interfaces through FastAPI and Streamlit

The project demonstrates end-to-end ownership across data processing, model training, quality assessment, inference serving, and interactive visualization in a portfolio-friendly scope.
