# Safety Notice

MediCheck is a research and education prototype built on synthetic EHR data.

- It does not use real patient data in the current version.
- It is a research and education prototype for software testing, portfolio demonstration, and learning.
- It is not a medical device.
- It must not be used for diagnosis, treatment, triage, prescribing, or clinical decision-making.
- Its data quality report is a synthetic-data heuristic and does not replace real clinical quality assessment.
- Risk scores shown in the API and dashboard are demonstration outputs for portfolio and research discussion purposes only.
- Any future extension to real-world clinical data would require IRB, privacy, governance, bias evaluation, and clinical validation workflows.
